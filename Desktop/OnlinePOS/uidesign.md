# Social Commerce SaaS
# UI/UX Design System Guide
## Tecunit Ghana

Design Direction:

```txt
Clean
Modern
Luxury
Classy
Soft
Elegant
Mobile-first
Minimal
Premium SaaS Feel
```

The product should feel like:

```txt
Stripe + Linear + Shopify + Notion
with feminine luxury aesthetics
```

---

# 1. DESIGN PHILOSOPHY

This platform is for:
- modern online sellers
- fashion brands
- beauty/cosmetics sellers
- lifestyle businesses
- premium small businesses

The UI should feel:
- calm
- organized
- soft
- premium
- fast
- simple

NOT:
- crowded
- corporate
- overly colorful
- cheap-looking
